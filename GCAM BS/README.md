# GCAM BS：43区开发与数据接入状态

更新日期：2026-11-05。

本目录记录当前GCAM PAC BS的工作进度。真实R源码统一在本仓库的[`input/gcamdata/R`](../input/gcamdata/R/)中维护镜像；本仓库不作为本地模型的运行输入。

## 当前源码

- 当前工程为43区、248个ISO，区域编号和ISO归属本轮未改。
- 436个R源码文件已经与当前本地工程逐字节同步，全部通过R语法解析，并核实加载的是当前PAC工程。
- 包含此前已实施的区域适配、农业数据连接、能源接口、风电、钢铁及排放链修正。源码同步不表示这些模块的所有数据已经完成科学验收。

## 排放XML进度的准确口径

2026-10-29的外部TEST_ONLY定向运行实跑135个共同依赖模块，写出22份目标XML。其中19份有内容且通过该轮独立验收，2份用户控制文件按Global默认未启用，1份工业城市XML仍有4项Inf。尚未运行gcam.exe或ModelInterface。

该轮只在内存中使用此前获准的18,401项价格测试值，没有将这些假设值写回正式CSV。最后4项工业系数未补1。新数据接入后须重新运行；本页不把旧轮结果当作新输入的验收结果。

## 本次能源数据

用户提供`WORLDBIG_1980_2025.zip`，内含两份World extended energy balances长表。先核对国家、产品、流量、单位、数值标记和现有GCAM接口，再决定对应项替换。

- 1980年以前不在本包范围内，不能补出1975年数据。
- 数值0旁的`M`标记表示缺失／不适用，不能称作确认的零能耗。
- 官方源中的估算或插补标记与本项目自行补值分开记录。
- 不更改43区ISO，不修改CEDS2025排放值，不把年度范围直接扩展到2025，不新增假设值来消除Inf。

已完成部分正式接入与L101实跑：60,708项按新来源更新，15,062项TES按现有规则重算，833,688项保留原输入并逐项登记。具体范围、验证与未更新原因见[本次接入说明](WORLDBIG_20261105_接入说明.md)。原始大型能源数据及本地测试XML不上传本公开源码仓库。
